# Attach to the owner's daily official QQ client via LLOneBot

The Target Account is the Owner's daily-use account on the same Windows PC, so the bridge must coexist with normal GUI chatting. NapCat Shell boots a second headless official QQ that cannot serve daily use, and NapCat's Framework mode relies on LiteLoaderQQNT, which is under-maintained and discouraged upstream since QQ 9.9.19. LLOneBot launches the installed official QQ through PMHQ with runtime injection, keeps the GUI fully usable, and exposes the same OneBot 11 forward WebSocket, so it is the first supported bridge; NapCat is demoted to a protocol-compatible but unverified alternative, and clientless protocol implementations (Lagrange) were rejected because of the sign-server dependency and ban risk on the Owner's primary account.
